# Breast Cancer Diagnosis -- Multi-Model Classifier Comparison

## a. Problem Statement

Breast cancer diagnosis from cell-nuclei measurements is a binary classification
problem: given a set of quantitative features extracted from a digitized image of
a fine needle aspirate (FNA) of a breast mass, predict whether the mass is
**malignant** or **benign**. Early, accurate diagnosis directly affects treatment
decisions, so this project compares five standard ML classification algorithms on
the same dataset to see which generalizes best for this task.

## b. Dataset Description

- **Source:** UCI Machine Learning Repository -- Breast Cancer Wisconsin (Diagnostic)
  Data Set (also available via `sklearn.datasets.load_breast_cancer`).
- **Instances:** 569
- **Features:** 30 numeric features (mean, standard error, and "worst" value for
  10 real-valued measurements per cell nucleus -- radius, texture, perimeter, area,
  smoothness, compactness, concavity, concave points, symmetry, fractal dimension).
- **Target:** `diagnosis` -- 0 = malignant, 1 = benign.
- **Class balance:** ~63% benign / ~37% malignant.
- **Split:** 80% train / 20% test (stratified), features standardized with
  `StandardScaler` fit on the training set only.

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Best overall performer (tied with SVM). With standardized features, the linearly separable structure of this dataset suits a linear decision boundary well -- highest AUC (0.9954) and MCC (0.9623), indicating strong, balanced separation between malignant and benign classes with very few errors on either side. |
| Decision Tree | Weakest of the five. A single tree (max_depth=5) overfits to a few dominant splits and loses the smooth margin that linear/kernel/distance-based models exploit here, giving the lowest accuracy (0.9211) and MCC (0.8341) -- recall in particular drops, meaning it misses more actual malignant cases than the other models. |
| KNN | Strong performer, and the only model with perfect recall (1.0000) -- it never misses a malignant case on this test split, at a small cost to precision (0.9600), i.e. a few more benign cases flagged as malignant. Distance-based classification works well once features are scaled, since the classes form fairly compact, separable clusters. |
| Naive Bayes | Middle of the pack. Its independence assumption between the 30 (often correlated) features is violated in this dataset (e.g. radius/perimeter/area move together), which caps its accuracy and MCC below the linear/kernel models, even though its AUC (0.9868) stays competitive -- it ranks probabilities well even when hard decisions are less precise. |
| Support Vector Machine | Matches Logistic Regression almost exactly (0.9825 accuracy, 0.9623 MCC) with a slightly lower AUC (0.9950). The RBF kernel finds a near-identical decision boundary to the linear model, suggesting the classes are close to linearly separable in the scaled 30-D feature space. |
| **Overall, Winner for your dataset?** | **Logistic Regression** (tied with SVM on accuracy/F1/MCC, but higher AUC: 0.9954 vs 0.9950). Given the dataset is close to linearly separable after scaling, Logistic Regression is the preferred winner for its simplicity, interpretability (coefficients map directly to feature importance), and lower computational cost versus SVM. |

## How to Run Locally

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python train_models.py      # trains models, writes model/*.joblib and test_data.csv
streamlit run app.py
```

## How the App Works

1. Upload a CSV containing all 30 feature columns plus the `diagnosis` target
   column (use the provided `test_data.csv` as a sample).
2. Pick a model from the sidebar dropdown, or compare all 5 at once.
3. The app loads the corresponding pre-trained model from `model/`, scales the
   uploaded features with the saved scaler, and computes predictions --
   **no retraining happens on uploaded data**.
4. Evaluation metrics (Accuracy, AUC, Precision, Recall, F1, MCC), a confusion
   matrix, and a classification report are displayed for the selected model.
